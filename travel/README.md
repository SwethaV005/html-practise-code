# TravelWise

## About the Project

A travel website created using HTML and CSS. The page includes a hero section, navigation menu, destination buttons, travel cards with pricing and booking buttons, and a footer. :contentReference[oaicite:0]{index=0}

## What I Learned

- Structured a webpage using semantic HTML elements such as `<header>`, `<main>`, `<section>`, and `<footer>`.
- Connected an external CSS file to the HTML page.
- Used CSS selectors to style different sections and elements.
- Used Flexbox to arrange navigation items, buttons, and content.
- Used CSS Grid to create a three-column layout for the tour cards.
- Learned how `padding`, `margin`, `gap`, and `box-sizing` control spacing and layout.
- Used `background-image` with a linear gradient overlay to improve text visibility over an image.
- Used `background-size: cover` and `background-position: center` to control the hero background image.
- Styled buttons with `border-radius`, `box-shadow`, and hover effects.
- Used `object-fit: cover` to control how images fit inside the cards.
- Added image hover animations using `transform: scale()` and `transition`.
- Practiced creating reusable card layouts using CSS classes.
- Used responsive-friendly layouts with Flexbox and Grid.

## Key Learning

This project helped me understand how HTML and CSS work together to build a structured and visually styled webpage, especially using Flexbox, Grid, background images, hover effects, and transitions.
