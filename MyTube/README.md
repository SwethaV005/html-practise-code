# MyTube

## About the Project

A simple YouTube-inspired webpage created using HTML. The page includes a header with a search bar, navigation menu, featured video, recommended videos, and a footer. :contentReference[oaicite:0]{index=0}

## What I Learned

- Created a webpage structure using HTML.
- Used `<header>`, `<nav>`, `<main>` content structure, and `<footer>`.
- Used HTML tables to organize the page layout.
- Created a search bar using `<input>` and `<button>`.
- Created navigation links using `<a>` tags.
- Used unordered lists with `<ul>` and `<li>` for the menu.
- Embedded YouTube videos using the `<iframe>` element.
- Learned how attributes such as `src`, `width`, `height`, `title`, and `allowfullscreen` control embedded content.
- Used `<hr>` to separate different sections of the page.
- Added a favicon using the `<link>` element.
- Practiced organizing content into sections such as featured videos and recommended videos.

## Key Learning

This project helped me understand how HTML tables can be used to structure a webpage and how external content such as YouTube videos can be embedded using iframes.
