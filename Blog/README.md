# Blog Website

## About the Project

A simple personal blog webpage created using HTML. The page contains a blog article, author information, social links, an image, related posts, a comment form, and a footer.

## What I Learned

- Created the basic structure of a webpage using HTML.
- Used headings and paragraphs to organize content.
- Added images using the `<img>` tag.
- Created links using the `<a>` tag.
- Used lists with `<ul>` and `<li>`.
- Used `<details>` and `<summary>` to create an expandable section.
- Created a comment form using `<form>`, `<label>`, `<input>`, `<textarea>`, and `<button>`.
- Learned how HTML attributes such as `href`, `src`, `alt`, `id`, `name`, `type`, and `required` are used.
- Added a favicon using the `<link>` element.
- Used `<hr>` and `<br>` to structure and separate content.
- Learned how different HTML elements work together to build a complete webpage.

## Key Learning

This project helped me understand how HTML is used to structure a webpage and create different sections such as content, navigation, images, forms, and footer.
