# Logitech TWS Products

## About the Project

A Logitech TWS products webpage created using HTML and JavaScript. The project displays product information dynamically using JavaScript and provides quantity controls, cart functionality, and product search. The HTML provides the basic page structure while JavaScript generates and manages the product content.

## What I Learned

- Connected JavaScript to an HTML page using the `<script>` tag with `defer`.
- Created an array of product objects containing product IDs, names, prices, and image paths. :contentReference[oaicite:1]{index=1}
- Used `map()` to generate product cards dynamically instead of hardcoding every product in HTML.
- Used template literals to insert product information into HTML.
- Used `innerHTML` to display dynamically generated products.
- Used functions to handle product quantity and cart operations.
- Used `find()` to locate products inside the basket and cart.
- Used `push()` to add products to the basket and cart.
- Used conditional statements to handle adding and removing quantities.
- Used `reduce()` to calculate the total number of items in the cart.
- Used `getElementById()` to access and update HTML elements.
- Added event listeners to make the search icon interactive.
- Implemented search filtering using the `input` event and `filter()`.
- Used `toLowerCase()` and `includes()` to perform product-name matching while typing. :contentReference[oaicite:2]{index=2}
- Updated the product display based on the search results.

## Key Learning

This project helped me understand how JavaScript can make a static HTML webpage interactive by dynamically generating content, handling user actions, managing product quantities and cart data, and filtering products based on user input.
